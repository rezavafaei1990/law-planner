# نسخه PWA همراه مطالعه حقوق

## نصب روی GitHub Pages
1. از مخزن فعلی خود یک نسخه پشتیبان بگیرید.
2. فایل‌های داخل این پوشه را در ریشه مخزن `law` بارگذاری کنید و فایل قبلی `index.html` را جایگزین کنید.
3. مطمئن شوید GitHub Pages از شاخه و پوشه‌ای که فایل‌ها در آن قرار دارند منتشر می‌شود.
4. پس از انتشار، سایت را با HTTPS باز کنید.

## نصب روی دستگاه
- Android: در Chrome سایت را باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را بزنید.
- iPhone/iPad: در Safari سایت را باز کنید، Share و سپس Add to Home Screen را انتخاب کنید.

## نکته فنی
این نسخه همان کد برنامه و اتصال Supabase قبلی را نگه می‌دارد. Service Worker فقط پوسته برنامه را cache می‌کند و درخواست‌های Supabase/Auth/Storage را cache نمی‌کند. برای ورود، جست‌وجوی داده‌های آنلاین و همگام‌سازی، اینترنت لازم است؛ آفلاین بودن کامل داده‌ها تضمین نشده است.
